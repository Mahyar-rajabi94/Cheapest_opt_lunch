# Historical agent results

These completed run artifacts were moved from the old per-task sandbox folders
without changing their bytes. `manifest.json` records each file's SHA-256 and the
source revision before cleanup. The original prompts, harnesses, optimizer copies
and campaign scripts remain recoverable from that revision in Git history.

These files are research records, not instructions or templates for a new run.
Use the root README and canonical AGENTS.md for current campaigns. New workspaces
must never include these previous results. Existing comparison scripts resolve
the historical runs here.
