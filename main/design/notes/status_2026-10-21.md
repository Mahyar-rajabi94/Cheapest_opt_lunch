## What existed before agent v2

- Baseline campaign (5 seeds for stochastic methods, 1 for deterministic local ones).
- Blind agent protocol, run once by a Claude agent and once by an OpenAI agent.

## Key findings
1. The Claude agent v1 solved it, but slower than plain L-BFGS-B: 1250 evals went to Sobol + CMA-ES on a smooth unimodal problem.
2. The OpenAI agent v1's final value equals standalone BOBYQA: its BOBYQA phase restarted from the box midpoint and threw away the CMA-ES incumbent.
3. TuRBO sign bug (fixed): the GP was fit on raw y but MaxPosteriorSampling maximizes.
4. Blind-test leak: the sandbox harness has `ioh.get_problem(8, ...)` in plain text.
5. Evidence is n=1 task, n=1 agent run each.
