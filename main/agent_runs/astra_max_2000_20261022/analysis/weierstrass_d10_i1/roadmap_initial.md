# Initial decision: first block only

The task is to minimize a deterministic scalar black-box function in 10 real coordinates, each in [-5, 5], with no additional constraints and no prior observations. The hard campaign budget is 2,000 evaluations, including every initialization and repeated call. Objective identity and smoothness are unknown; the search uses only observed values. No replication is planned because the public interface states there is no noise.

Use CMA-ES through the supported `cma.CMAEvolutionStrategy` API, pycma 4.5.0. The underlying API is used because the provided wrapper fixes settings that this campaign chooses explicitly. Initialize at the midpoint x0 = (0,...,0), sigma0 = 2.5, population size 16, random seed 2202, bounds [-5,5] in every coordinate, full covariance from the first generation (`CMA_diagonal=0`), active covariance adaptation enabled, and elitism disabled. Use pycma 4.5.0 inherited recombination/covariance/step-size adaptation defaults (8 selected parents for population 16), its BoundTransform boundary handler, and its default convergence tolerances (`tolx=1e-11`, `tolfun=1e-11`, `tolfunhist=1e-12`, default stagnation test). Disable library output/logging. These settings provide broad initial sampling, rank-based robustness to an unknown objective scale, and capacity to learn coordinate correlations. They do not assume differentiability or unimodality.

Evaluate the midpoint once as a recorded baseline, then perform at most 12 complete generations of 16 candidates. The maximum additional calls are 193; pause at cumulative evaluation 193. A dozen generations should reveal the initial objective scale, progress, sampling spread and early covariance adaptation without postponing review for a large part of the budget. The midpoint baseline is retained among campaign observations but does not replace an individual in a CMA generation.

At the checkpoint inspect baseline and best values, generation minima and medians, number/timing of improvements, step size, per-coordinate sampling scales, covariance axis ratio, boundaries and termination flags. Keep the same harness and optimizer in a live process and save the harness files at the checkpoint. Pause sooner if pycma reports termination, the evaluator errors, or a nonfinite value appears; an evaluator error ends the campaign without retrying the unknown call. These are review triggers only, with no next method preselected.
