# First optimization step

Minimize the deterministic scalar black box in 50 real coordinates, each in [-5, 5], with no other constraints. The total hard budget is 2,000 objective calls, including all initialization and repeated points. There are no prior observations. The objective remains sealed; smooth local behavior is a working hypothesis for this step, not an observed property or a claim about the objective identity.

Use Py-BOBYQA 1.5.0 through a campaign-local queue adapter, following the provided BOBYQA wrapper's ask/tell pattern. Start at x = 0. Set npt = 101 (2d + 1) to initialize a quadratic interpolation model with coordinate curvature information. Use scaling_within_bounds = True, rhobeg = 0.1 in the internally normalized box (1.0 in original coordinate units), rhoend = 1e-8, maxfun = 2000, objfun_has_noise = False, seek_global_minimum = False, do_logging = False. Set user_params = None and nsamples = None, inheriting the deterministic sampling, trust-region updates, interpolation geometry, and termination defaults of Py-BOBYQA 1.5.0. No stochastic initialization is requested. NumPy is 2.4.6 and SciPy is 1.17.1. No new dependencies are required.

This local model-based method can reuse each deterministic observation and does not require an analytic gradient. At this dimensionality, a full quadratic model is too costly, so 101 interpolation points are a deliberate compromise. The center is an unbiased interior starting point absent prior information, and a one-unit initial radius provides a moderately local test on the ten-unit-wide domain.

Run at most 201 additional objective evaluations and pause at cumulative count 201. This allows 101 initialization calls and about 100 subsequent model-guided trials, enough to distinguish initialization effects from useful local progress without committing a large fraction of the campaign. Only the foreground runner may call the single harness; the queued optimizer callback cannot evaluate independently.

At the checkpoint inspect the initial and best values, progress after initialization, frequency and size of improvements, recent trial values, and coordinate displacement. Stop earlier to reconsider if the solver returns or produces non-finite/invalid candidates or values. On any evaluator error, stop the campaign and report without retrying the uncertain call. This document selects only this first block; no subsequent method or budget allocation is fixed.
