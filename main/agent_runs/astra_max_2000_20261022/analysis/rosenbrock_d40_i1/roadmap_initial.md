# Initial decision: one BOBYQA block

Minimize the deterministic scalar black box in 40 real coordinates, each in [-5, 5], with no other constraints and a hard total budget of 2,000 objective calls. There are no prior observations. The function identity and optimum remain private; only the public evaluator API and optimizer implementations are used. Determinism is given; smoothness and global basin structure are unknown. This first step tests whether a local quadratic approximation supports useful descent, without assuming that a local result is globally optimal.

Use Py-BOBYQA 1.5.0 through a campaign-local thread/queue adapter based on the provided wrapper's ask/tell pattern. Start at x = (0,...,0). Use npt = 2*d+1 = 81, scaling_within_bounds = True, rhobeg = 0.1 (one coordinate unit in the original box), rhoend = 1e-8 (1e-7 original units), maxfun = 2000, objfun_has_noise = False, seek_global_minimum = False, and one sample per proposed point. Explicitly disable automatic restarts. Retain the library's deterministic coordinate-direction initialization and minimum-change Hessian model. Inherited Py-BOBYQA 1.5.0 trust-region defaults: eta1 = 0.1, eta2 = 0.7, gamma_dec = 0.5, gamma_inc = 2, gamma_inc_overline = 4, alpha1 = 0.1, alpha2 = 0.5; all other unspecified settings use that version's defaults. Enable in-memory diagnostic collection, with expensive poisedness logging disabled; no solver logs are written to the results directory. Label calls `bobyqa_local`.

This is an evaluation-efficient local model for a deterministic, moderately high-dimensional problem: the 81-point interpolation model estimates coordinate curvature without paying for a full 861-coefficient quadratic fit. The initial radius tests a meaningful 10% of each coordinate's range without placing the initial points on the boundaries.

The first step permits at most 161 additional objective calls and pauses at cumulative evaluation 161. This covers the 81 initialization calls and up to 80 subsequent calls, enough to observe model-guided progress while keeping the first checkpoint early. The main thread alone calls the harness and enforces both the step cap and the total budget. The same harness, observations, and live optimizer state remain available across checkpoints.

At the checkpoint inspect the initial objective, best value, improvements over successive parts of the block, the distribution of observed values, coordinate-probe sensitivity, distances between proposals, and boundary proximity. Pause sooner if the solver terminates or reports a numerical failure. On any evaluator error or nonfinite response, stop immediately and report without retrying an unknown evaluation. A short plateau alone is not a stopping condition and does not establish that local modeling is unsuitable. No later method or budget allocation has been selected.
