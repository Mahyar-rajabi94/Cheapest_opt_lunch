# Initial decision: space-filling design with a history probe

The task is to minimize the public scalar objective in 11 coordinates, each in [0,1], with no other constraints and a hard budget of 100 calls. There are no prior observations. The interface specifies no measurement noise but explicitly states that evaluations depend on preceding points. Thus identical inputs need not return identical values; observations will remain indexed by evaluation order, and repeated values will not be averaged as IID noise. No stationarity, optimum, or function identity is assumed. Only the public interface and optimizer wrappers have been read.

## First block only
Use the supplied SobolSearch ask/tell implementation, backed by scipy 1.17.1 scipy.stats.qmc.Sobol, with dimension 11, scramble=True, campaign seed=2, bounds [0,1]^11. Inherited scipy defaults are bits=30 and optimization=None. NumPy is 2.4.6. Start the sequence once and retain it. Evaluate the center [0.5]*11 first, then 16 Sobol points in generated order, then the center again. Label all calls sobol_anchor. This is a space-filling initial experiment; there is no evidence yet to favor a region or length scale. The power-of-two design preserves Sobol balance. The two center observations probe the magnitude of history dependence without interpreting it as random noise.

Maximum additional calls: 18. Pause at cumulative evaluation 18. Sixteen diverse locations give initial objective range and coarse spatial information in 11 dimensions; the two anchor calls quantify one history-associated change. This is enough to inform a fresh method decision while retaining 82 calls. No later method or budget allocation is selected.

At the checkpoint inspect all observed values, best value and location, objective range, center change relative to that range, and the relationship of values to evaluation order and coordinates. A single anchor difference cannot identify how history enters the objective, so interpret it cautiously. Stop immediately on any evaluator error, nonfinite value, bounds violation, or budget inconsistency; do not retry an unknown evaluation. The process enforces both this block limit and the total budget before each call, saves the harness output, and returns control for a new decision.
